# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works
with multi-package repos, or single-package repos to help you keep track of changes. This package will use it to manage versioning and changelogs.

## What are Changesets?

If you want to know more about changesets, we recommend reading [the official documentation](https://github.com/changesets/changesets).

## Adding a Changeset

To add a changeset, run:

```bash
bun run changeset:add
```

This will prompt you to:
1. Select the type of change (major, minor, patch)
2. Write a summary of the change

The changeset will be added to the `.changeset` directory.

## Releasing

When you're ready to release:

1. Run `bun run changeset:version` to update versions and generate changelogs
2. Commit the changes
3. Run `bun run changeset:publish` to publish to npm

Or use the GitHub Actions workflow which automates this process!
